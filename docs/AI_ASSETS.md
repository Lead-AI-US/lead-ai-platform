# AI Assets

AI Assets is a metadata registry for external AI and data resources.

Supported future references:

- GitHub repositories
- Hugging Face models
- Hugging Face datasets
- Hugging Face Spaces
- Kaggle datasets
- Kaggle notebooks

The current UI shows empty, not-configured states until provider authorization and metadata sync exist.

Do not copy model weights, large datasets, notebooks, or private provider content into Firestore by default. Store only workspace-scoped metadata references.
